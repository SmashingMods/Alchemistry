# Alchemistry 1.20.2-2.4.1 RELEASE

Alchemistry is now on NeoForge! This is the first NeoForge release, for Minecraft 1.20.2. Note that old 1.20.1 (Forge) worlds are not compatible. Requires ChemLib and AlchemyLib for this version.

Changes:
- Ported from Forge to NeoForge for Minecraft 1.20.2.
- All machines, reactors, recipes, and the guidebook carry over from the previous version.
